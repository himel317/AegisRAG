# Security Policy

## About AegisRAG

AegisRAG is an AI-powered cybersecurity research framework designed to detect and prevent Prompt Injection and Data Poisoning attacks in Retrieval-Augmented Generation (RAG) systems.

Security, privacy, and responsible development are important aspects of this project.

## Supported Versions

Security issues should be reported against the latest available version of AegisRAG.

## Reporting a Vulnerability

If you discover a potential security vulnerability in AegisRAG, please report it responsibly.

A vulnerability report should include:

- A clear description of the issue.
- Steps to reproduce the vulnerability.
- Potential security impact.
- Relevant logs or screenshots with sensitive information removed.

Please avoid publicly disclosing exploitable vulnerabilities before they have been reviewed.

## Security Best Practices

Users and contributors should:

- Never commit API keys, passwords, or authentication secrets.
- Store credentials in environment variables.
- Use strong authentication secrets.
- Validate uploaded documents.
- Protect database and vector storage files.
- Restrict access to sensitive resources.
- Keep dependencies updated.
- Review security configurations before deployment.

## Responsible Use

AegisRAG is intended for academic research, educational purposes, and authorized security testing.

Users are responsible for ensuring that their activities comply with applicable laws and authorization requirements.

## Project Security Status

AegisRAG is an actively developed academic research project.

It has not been independently security-certified. Further security testing and deployment validation are required before production use.

## Contact

For security-related concerns, please use the repository's private communication channels where available.
